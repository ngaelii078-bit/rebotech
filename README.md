# Rebotech

A static website for Rebotech Engineering, featuring its services, workshop and contact details.

## Run locally

Run `node server.cjs` from this directory, then open [http://localhost:3001](http://localhost:3001).

The site files are in `dist/`. The hero video is representative stock footage from [Pexels](https://www.pexels.com/video/sparks-flying-while-a-man-is-working-with-metal-11887093/).
