# Rebotech

A static website for Rebotech Engineering, featuring its services, workshop and contact details.

## Run locally

Run `node server.cjs` from this directory, then open [http://localhost:3001](http://localhost:3001).

The site files are in `dist/`. All photography is Rebotech's own (company profile). Design direction and rules are in `../TASTE.md`.

`dist/assets/hero-video.mp4` (Pexels stock footage) is no longer used by the page and can be deleted to cut 8.8 MB from the deploy.
